Breve História da Web
A Web nasceu em 1989–1991 no CERN, com Tim Berners-Lee, combinando
três invenções: HTML (documentos), HTTP (transporte) e URL
(endereçoamento).


            Web 1.0 — Anos 90
    1       Páginas estáticas, somente leitura. Ex: sites institucionais,
            portais.


            Web 2.0 — Anos 2000
    2       Conteúdo gerado pelo usuário, interatividade, AJAX. Ex: redes
            sociais, wikis.


            Web Moderna
    3       SPAs, APIs, mobile, tempo real. Ex: Gmail, WhatsApp Web,
            bancos.

A Web funciona em qualquer navegador e dispositivo porque é construída sobre padrões abertos. Escrever código conforme o
padrão — e não "para o navegador X" — garante compatibilidade universal.

Publicando com GitHub
Pages
Todo repositório público do GitHub pode virar um site estático publicado
gratuitamente.


 1     Settings → Pages
       No repositório, acesse Settings   → Pages.

 2     Escolha a Branch
       Em Source, selecione a branch main e a pasta raiz (/).



 3     Deploy Automático
       Seu site estará em https://usuario.github.io/meu-projeto/. A cada git
       push, o site é atualizado automaticamente — seu primeiro fluxo de
       deploy.
