O modelo cliente-servidor

                                                                   requisição HTTP
                          Cliente                                                    Servidor
                          navegador                                                  responde requisições
                                                                   resposta HTTP



    O que acontece quando você digita um endereço:

         1        DNS resolve o domínio para um endereço IP

         2        Abre conexão TCP com o servidor (criptografia TLS/HTTPS)

         3        Envia a requisição HTTP — ex.: GET /index.html

         4        Servidor devolve: código de status + cabeçalhos + conteúdo

         5        Navegador renderiza o HTML e baixa CSS, JS, imagens e fontes

As máquinas viraram clientes — e pagam
Já existe infraestrutura comercial para vender serviços a agentes de IA, sem nenhum humano na tela:

                        x402 (Coinbase, 2025)
                        Ressuscitou o status HTTP 402 “Payment Required” — reservado desde os anos 90 e nunca usado. O agente recebe
                        402 com o preço, paga e refaz a requisição. Sem checkout, sem cadastro. 100 milhões de pagamentos nos primeiros
                        6 meses; CoinMarketCap cobra US$ 0,01 por chamada de API.


                        Redes de pagamento p/ agentes
                        Mastercard Agent Pay, Visa Trusted Agent Protocol e o AP2 do Google (60+ parceiros: PayPal, Amex, Adobe…) dão
                        identidade e cartão às máquinas. Em 2026, Santander e Mastercard executaram o 1º pagamento europeu ponta a ponta
                        feito por um agente de IA.


                        MCP (2024→Linux Foundation)

                        Padrão aberto que conecta assistentes de IA a dados e ferramentas de forma padronizada — milhares de serviços já
                        expõem “portas para agentes” em vez de telas para humanos.

    Estamos construindo para o consumidor certo?
     O agente não quer o botão azul. Ele quer o dado, o serviço, a resposta — em JSON, via API, de forma padronizada e
     confiável.

     A informação vira o produto. APIs bem projetadas, dados estruturados e documentação clara passam a ser a
     “fachada” principal do sistema.

     A interface vira sob demanda. O humano continua importando — mas a tela pode ser montada na hora, quando e
     como ele precisar.


     Tudo que vamos aprender aqui — HTML semântico, HTTP, APIs REST, JSON, Express — serve aos dois públicos.

Publicando no GitHub
Conectar o repositório local a um repositório remoto criado no GitHub:


       git remote add origin https://github.com/usuario/meu-projeto.git
       git branch -M main
       git push -u origin main

       # nos próximos envios, basta:
       git push

    Então por que ainda estudar a fundo?

     Você usa Assembly hoje? Quase nunca — mas em Arquitetura você estuda, pra entender o que o sistema operacional e
     o hardware fazem por baixo.

     Você fala HTTP na mão? Não — mas como profissional de sistemas você precisa saber o que são portas, sockets e
     requisições para depurar quando quebra.

     Com IA, a mesma regra vale. Ela escreve o código, mas quem julga se está certo, seguro e bem arquitetado é você. Só
     revisa bem quem entende a base.


     Estamos em transição. Quem domina a fundo E usa as ferramentas sai na frente — esse é o objetivo desta disciplina.
