2. Node.js: JavaScript fora do navegador

O Node.js (2009) pegou o V8 — o motor JavaScript do Chrome — e o levou para fora do navegador. Com ele, JS passou a acessar o que o
navegador proíbe: arquivos do disco, rede em baixo nível, portas, bancos de dados. Nasceu aí o full-stack JavaScript: uma língua
só, do front ao back — e é exatamente por isso que a transição de vocês será suave: const , arrow functions, async/await , objetos e
arrays funcionam identicamente.
Verifique a instalação (feita lá na Aula 1) e experimente o Node como executor de scripts:

 node --version         # v22.x (LTS)
 npm --version

 # olamundo.js
 console.log("JavaScript rodando no terminal, sem navegador!");

 node olamundo.js


Diferenças de ambiente que importam: no Node não existem document , window nem DOM — não há página. Em compensação existem
módulos como fs (arquivos) e http (rede), além do ecossistema npm.

2.1 npm: o gerenciador de pacotes
O npm instala bibliotecas do maior repositório de código do mundo e registra tudo no package.json — a certidão do projeto:

 mkdir api-projeto && cd api-projeto
 npm init -y                       # cria o package.json
 npm install express               # baixa o Express para node_modules/


  GIT + NODE: REGRA IMEDIATA
  A pasta node_modules/ pode ter dezenas de milhares de arquivos e nunca vai para o repositório. Crie um arquivo .gitignore com
  a linha node_modules/ antes do primeiro commit. Quem clonar o projeto roda npm install e o npm reconstrói tudo a partir do
  package.json .




3. Express: o framework do servidor

Dá para criar um servidor só com o módulo http do Node — mas é verboso. O Express é o framework minimalista que se tornou padrão
do ecossistema: rotas, tratamento de requisição/resposta e middlewares em poucas linhas.

3.1 O primeiro servidor

 // server.js
 const express = require("express");
 const app = express();
 const PORTA = 3000;
 app.get("/", (req, res) => {
   res.send("<h1>Meu primeiro servidor Express!</h1>");
 });

 app.listen(PORTA, () => {
   console.log(`Servidor rodando em http://localhost:${PORTA}`);
 });



 node server.js
 # abra http://localhost:3000 no navegador — você acabou de atender
 # uma requisição HTTP igual às que estudamos na Aula 1


Anatomia da rota: app.get(caminho, callback) — o método HTTP ( get / post / put / delete ) vira o nome da função, e o callback recebe req
(a requisição: o que o cliente mandou) e res (a resposta: o que devolveremos). Reconheça o padrão: é o mesmo modelo de callbacks dos
eventos — só que o "evento" agora é uma requisição chegou.

3.2 Reinício automático durante o desenvolvimento
Alterou o código? O servidor precisa reiniciar. Automatize com o modo watch e um script npm:

 // package.json
 "scripts": {
   "dev": "node --watch server.js"
 }

 npm run dev      # reinicia sozinho a cada arquivo salvo




4. Servindo o site + criando a API

4.1 Arquivos estáticos: seu projeto sai do Live Server
Coloque o site das Unidades 1-2 numa pasta public/ e o Express o entrega inteiro com uma linha:

 api-projeto/
 ├── public/                 # seu site: index.html, css/, js/, img/
 ├── server.js
 ├── package.json
 └── .gitignore

 // server.js
 app.use(express.static("public"));
 // http://localhost:3000 agora serve o index.html e todos os assets


4.2 Endpoints JSON: o outro lado do fetch
Na Aula 10 vocês consumiram a JSONPlaceholder. Agora vocês são a JSONPlaceholder:

 const produtos = [
   { id: 1, nome: "Camiseta", preco: 49.9, categoria: "vestuario" },
   { id: 2, nome: "Caneca",   preco: 24.9, categoria: "casa" }
 ];

 // GET /api/produtos → a lista completa
 app.get("/api/produtos", (req, res) => {
   res.json(produtos);                         // serializa e define Content-Type
 });

 // GET /api/produtos/2 → um item (parâmetro de rota)
 app.get("/api/produtos/:id", (req, res) => {
   const id = Number(req.params.id);        // params chegam como string!
   const produto = produtos.find(p => p.id === id);   // find da Aula 8

   if (!produto) {
     return res.status(404).json({ erro: "Produto não encontrado" });
   }
   res.json(produto);
 });


E no front-end, dentro de public/js/app.js , o fetch da Aula 10 muda apenas o endereço:

 const resposta = await fetch("/api/produtos");       // mesma origem: caminho relativo
 const dados = await resposta.json();
 render(dados);
