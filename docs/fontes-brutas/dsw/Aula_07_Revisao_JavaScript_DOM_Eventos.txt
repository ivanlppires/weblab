2. JavaScript na página

Vimos na Aula 2 que o JS mora em arquivo próprio ( js/app.js ), vinculado ao HTML. A forma moderna usa defer no <head> : o navegador
baixa o script em paralelo e o executa somente após montar o DOM — assim seus seletores nunca encontram uma página pela
metade:

 <head>
   ...
   <script src="js/app.js" defer></script>
 </head>


Seu melhor amigo na Unidade 2 é o Console ( F12 → Console): erros aparecem ali (com arquivo e linha), e console.log(valor) permite
inspecionar qualquer coisa durante a execução. Programe com o Console sempre aberto.

3.1 Variáveis e tipos

 const curso = "Desenvolvimento Web"; // não será reatribuída → const (padrão)

 const nome = "Maria";
 const msg = `Olá, ${nome}! Sua nota é ${nota >= 6 ? "aprovado" : "exame"}.`;
 // crase (`) permite interpolar ${expressões} e quebrar linha no texto


3.3 Comparação: sempre com ===

 5 == "5"    // true → compara convertendo tipos (armadilha!)
 5 === "5"   // false → compara valor E tipo. Use sempre === e !==




4. Funções: blocos de comportamento
  // Declaração clássica
  function calcularMedia(a1, a2, a3) {
    return (a1 + a2 + a3) / 3;
  }

  // Função com parâmetro padrão
  function saudar(nome = "visitante") {
    return `Bem-vindo(a), ${nome}!`;
  }

  calcularMedia(8, 7, 9);    // 8
  saudar();                  // "Bem-vindo(a), visitante!"


Em JavaScript, funções são valores: podem ser guardadas em variáveis e passadas como argumento para outras funções. Essa ideia —
que parece um detalhe — é a chave de tudo na próxima aula (callbacks e arrow functions) e de toda a programação assíncrona da
Unidade 2. Você já vai usá-la hoje, no addEventListener .


5. Objetos e arrays: organizando dados

5.1 Objetos: pares chave-valor

  const produto = {
    nome: "Camiseta",
    preco: 49.9,
    emEstoque: true,
    exibir() {                              // método: função dentro do objeto
      return `${this.nome} — R$ ${this.preco.toFixed(2)}`;
    }
  };

  produto.nome;              // "Camiseta" (notação de ponto)
  produto["preco"];          // 49.9 (notação de colchetes)
  produto.preco = 39.9;      // alterar
  produto.categoria = "Vestuário"; // adicionar nova propriedade
  produto.exibir();          // "Camiseta — R$ 39.90"


  POR QUE OBJETOS IMPORTAM TANTO
  Objetos são o formato universal de dados na Web: o DOM é um objeto, o evento que chega no clique é um objeto, e o JSON que
  trafega entre navegador e servidor (aulas de AJAX e Express) é literalmente a notação de objetos do JavaScript. Dominar objetos
  agora é investir nas duas próximas unidades.


5.2 Arrays: listas ordenadas

  const notas = [8, 7.5, 9, 6];
  notas.length;        // 4
  notas[0];            // 8 (índice começa em 0)
  notas.push(10);      // adiciona ao final

  // Percorrendo — forma moderna:
  for (const n of notas) {
    console.log(n);
  }

  // Array de objetos: o formato mais comum em aplicações reais
  const carrinho = [
    { nome: "Camiseta", preco: 49.9 },
    { nome: "Boné", preco: 29.9 }
  ];

Na Aula 2 vimos que o navegador transforma o HTML no DOM — a página viva na memória. O JS enxerga esse DOM pelo objeto global
document :


6.1 Selecionando elementos

  const titulo = document.querySelector("h1");          // primeiro que casa
  const btn = document.querySelector("#btn-enviar");     // por id
  const cards = document.querySelectorAll(".card");      // TODOS (NodeList)
  // querySelector aceita qualquer seletor CSS — o conhecimento da Unidade 1 vale aqui
6.2 Alterando conteúdo, atributos e estilo

 titulo.textContent = "Novo título";            // texto puro (seguro)
 titulo.innerHTML = "Novo <em>título</em>";     // interpreta HTML (cuidado!)

 btn.setAttribute("aria-expanded", "true");     // atributos
 btn.disabled = true;                           // propriedades diretas

 // Estilo: prefira alternar CLASSES a estilos inline —
 // o visual continua no CSS, o JS só liga/desliga estados:
 card.classList.add("destaque");
 card.classList.remove("oculto");
 card.classList.toggle("aberto");     // adiciona se não tem, remove se tem


  TEXTCONTENT × INNERHTML
  Nunca use innerHTML com texto vindo do usuário (campo de formulário, URL): um valor como <script>...</script> seria interpretado
  — a porta do ataque XSS. Para texto, textContent sempre. Voltaremos à segurança na Unidade 3.


6.3 Criando elementos

 document.querySelector("#lista").appendChild(li);




7. Eventos: reagindo ao usuário

Evento é qualquer acontecimento na página: clique, tecla, envio de formulário, rolagem. O padrão profissional é addEventListener(tipo,
função) — repare: passamos uma função como argumento (a ideia da seção 4 em ação):


 const botao = document.querySelector("#btn-tema");

 botao.addEventListener("click", function (evento) {
   console.log(evento.target);        // o elemento clicado
   document.body.classList.toggle("tema-escuro");
 });


 Evento                               Dispara quando...

 click                                Clique/toque em um elemento.

 submit                               Formulário é enviado (no <form> , não no botão).

 input / change                       Valor de um campo muda (a cada tecla / ao concluir).

 keydown                              Tecla pressionada (ex.: fechar menu com Esc).

 DOMContentLoaded                     DOM terminou de montar (dispensável se usar defer ).


7.1 Fechando o ciclo da Aula 6: menu hambúrguer acessível
Na aula passada deixamos o aria-expanded estático. Agora completamos o componente:

 // js/app.js
 const toggle = document.querySelector(".menu-toggle");
 const menu = document.querySelector("#menu");

 toggle.addEventListener("click", function () {
   const aberto = menu.classList.toggle("aberto");
   toggle.setAttribute("aria-expanded", aberto);   // true/false sincronizado
 });

 document.addEventListener("keydown", function (e) {
   if (e.key === "Escape" && menu.classList.contains("aberto")) {
     menu.classList.remove("aberto");
     toggle.setAttribute("aria-expanded", "false");
     toggle.focus();                               // devolve o foco ao botão
   }
 });


7.2 Interceptando o envio de formulário
Prévia do que aprofundaremos na avaliação (critério "validação de formulários"):

 const form = document.querySelector("#form-contato");

 form.addEventListener("submit", function (e) {
    e.preventDefault();                // impede o envio padrão (recarregar a página)
    const nome = form.nome.value.trim();
    if (nome === "") {
      document.querySelector("#erro-nome").textContent = "Informe seu nome.";
      form.nome.focus();
      return;
    }
    console.log("Formulário válido — enviaremos via AJAX na aula de 13/10!");
  });
