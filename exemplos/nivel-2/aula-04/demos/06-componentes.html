A tag não é escolhida pelo tamanho da fonte. No projeto, o título do card é <h3 class="h5">: a tag define a hierarquia do documento (é h3 porque está dentro de uma seção com h2); a classe define só o tamanho visual.

3. Formulário — três classes resolvem quase tudo

Como você quer ser chamado no atendimento.
  • form-control → input, textarea e afins.
  • form-select → select. Esquecer esta é o motivo nº 1 de "o formulário continua com cara antiga".
  • form-check + form-check-input + form-check-label → caixas e rádios.
Teste ao vivo: digite duas letras no nome, saia do campo com Tab. A borda fica vermelha — e isso é :user-invalid, CSS puro, não o sistema de validação do Bootstrap. O sistema dele (needs-validation, is-invalid) exige JavaScript autoral, proibido nesta unidade. Você o adota na Unidade 2, quando o js/app.js existir.
