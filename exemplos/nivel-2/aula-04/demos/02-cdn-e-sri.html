Demo 02 — §3. Como um framework chega até a página

Três coisas para mostrar: versão fixa na URL, hash SRI e o que acontece quando a hash não bate. Deixe o console (F12) aberto durante toda a demonstração.

Esta página em si já é a prova: ela carrega o Bootstrap por CDN, com hash correta.

1. Versão flutuante × versão fixa

Armadilha
https://cdn.jsdelivr.net/npm/bootstrap/dist/css/bootstrap.min.css

"Me dê a mais recente." No dia em que sair o Bootstrap 6, o seu site muda de layout sozinho — sem você ter feito um único commit.

Correto
https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css

A versão está travada. O site continua idêntico até você decidir mudar — e a mudança fica registrada no histórico do Git.

2. A hash não é mágica: calcule na frente da turma

Rode no terminal, com a turma olhando:

curl -sO https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css
openssl dgst -sha384 -binary bootstrap.min.css | openssl base64 -A

A saída é, byte a byte, o valor que está no integrity desta página:

QWTKZyjpPEjISv5WaRU9OFeRpok6YctnYmDr5pNlyT2bRjXh0JMhjY6hW+ALEwIH

O script ferramentas/verificar-sri.sh faz isso e ainda repete o cálculo depois de acrescentar um único espaço no fim do arquivo — para a turma ver a hash inteira mudar por causa de um byte.

3. Hash quebrada, ao vivo

Os dois quadros abaixo carregam o mesmo arquivo da mesma CDN. No da esquerda, trocamos o primeiro caractere da hash de Q para Z. O navegador bloqueia o CSS inteiro.

integrity errado abrir sozinha

integrity correto abrir sozinha

No console: Failed to find a valid digest in the 'integrity' attribute for resource … The resource has been blocked. Essa frase inteira está na tabela de 🐛 Erros comuns da aula — mostre a mensagem real antes de mostrar a tabela.

4. O que a hash não protege

  • Não impede a CDN de saber quem visitou o seu site: cada usuário faz uma requisição para lá.
  • Não serve para conteúdo gerado a cada requisição — por isso o Play CDN do Tailwind e o esm.run do Material Web não publicam hash (§7.1).
  • Garante uma coisa só, e garante bem: o arquivo que chegou é o que eu esperava.
