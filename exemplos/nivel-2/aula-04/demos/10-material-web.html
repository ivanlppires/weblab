Na aba Elements: abra a seta de <md-filled-button>. Dentro dela aparece #shadow-root — uma árvore de elementos com CSS isolado da página. Você não escreve <button class="md-button">: escreve uma tag que não existe no HTML e que o JavaScript registrou.

Teste que fecha o argumento da §6.3: no DevTools, aba Network, marque Disable JavaScript (ou bloqueie o esm.run) e recarregue. Os campos e os botões desaparecem da tela — viram tags desconhecidas. Um site Bootstrap sem JavaScript perde o menu hambúrguer; um site Material Web sem JavaScript perde tudo.

Troque duas variáveis (--md-sys-color-primary e --md-sys-color-on-primary) e a interface inteira se recolore — exatamente a ideia das --bs-*, com outro nome.
