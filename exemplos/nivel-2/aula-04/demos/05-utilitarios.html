2. O lado: t b s e x y

s é start e e é end — não left e right. Existe para o mesmo CSS funcionar em árabe, escrito da direita para a esquerda.

ms-auto dentro de um flex é o truque mais usado do framework — é o que joga o menu da navbar para a direita, na Demo 06.
