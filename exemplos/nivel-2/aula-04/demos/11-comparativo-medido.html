Demo 11 — §7.2. Meça, não ache

Os três quadros abaixo mostram o mesmo grid de seis cards, com o mesmo conteúdo e o mesmo comportamento responsivo (1 / 2 / 3 colunas). Muda só o framework. Esta página é a bancada do desafio ⭐⭐ O mesmo componente, três vezes.

Como medir, em trinta segundos: abra cada quadro em uma aba própria (links abaixo) → F12 → aba Network → marque Disable cache → Ctrl+Shift+R → ordene por Size e leia a coluna Transferred (o que veio pela rede, comprimido), não a coluna Size. O rodapé do painel mostra o total agregado.

A tabela que a turma preenche

Os valores abaixo são de uma medição feita em rede doméstica. Refaçam a medição na aula — o número de vocês é que vale.

Mesmo grid de seis cards, três frameworks
Framework O que vem pela rede Ordem de grandeza Linhas de HTML do card Grid Hash SRI
Bootstrap 5.3 CSS completo + bundle JS ~32 KB + ~25 KB 12 linhas, 9 classes pronto, 12 colunas sim
Tailwind 4 (Play CDN) o compilador, não o CSS final ~90 KB 12 linhas, 31 classes utilitários de grid/flex não (conteúdo gerado)
Material Web 2 módulos ES + fonte Roboto ~120 KB + 12 linhas + CSS Grid à mão não tem não (módulo importa outros)
A comparação honesta que quase ninguém faz: os ~90 KB do Tailwind aqui são o compilador rodando no navegador. O Tailwind de produção passa por build e entrega poucos KB — provavelmente menos que o Bootstrap. Comparar peso sem dizer em qual etapa do processo a medição foi feita é como comparar o peso de um carro com o da fábrica.

A pergunta de manutenção (a mais importante)

Mude a cor da marca em todos os seis cards. Quantas linhas você toca?

  • Bootstrap: 1 linha — --bs-btn-bg em .btn-cafe.
  • Tailwind com @theme: 1 linha — --color-cafe.
  • Tailwind sem @theme: 6 ou 12 ocorrências de bg-amber-800 caçadas no HTML.
  • Material Web: 1 linha — --md-sys-color-primary, e recolore tudo, inclusive o que você não queria.
E a conclusão que a §7.2 cobra: abra a aba Network do site do Café Cerrado. Os dois arquivos do framework somam ~57 KB. Uma única foto mal exportada pesa mais que os dois juntos. É aí que quase sempre está o problema real de desempenho do site de um aluno.
