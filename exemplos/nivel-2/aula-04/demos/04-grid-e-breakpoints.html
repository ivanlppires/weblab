A borda tracejada é a row. Repare que ela "vaza" para fora do container: é a margem negativa que compensa o padding das colunas (a calha). É exatamente por isso que uma col-* fora de uma row fica com um espaço estranho na borda.

2. Leia como três frases

<div class="col-12 col-md-6 col-lg-4">

No celular ocupa a linha inteira (12/12); no tablet, metade; no notebook, um terço. Os três blocos abaixo têm essa classe — arraste a janela:

Bloco 1
col-12 col-md-6 col-lg-4
Bloco 2
col-12 col-md-6 col-lg-4
Bloco 3
col-12 col-md-12 col-lg-4
Mobile-first: col-md-6 quer dizer "6 colunas a partir de 768 px", nunca "apenas no tablet". Por isso se escreve col-12 col-md-6 — do menor para o maior — e nunca o contrário.

4. container × container-fluid

container — largura máxima por breakpoint, centralizado
container-fluid — 100 % da largura, sempre

5. Por baixo do capô — é CSS comum

.row {
  --bs-gutter-x: 1.5rem;
  display: flex;
  flex-wrap: wrap;
  margin-right: calc(-0.5 * var(--bs-gutter-x));
  margin-left: calc(-0.5 * var(--bs-gutter-x));
}

.row > * {
  flex-shrink: 0;
  width: 100%;                                    /* ← por que a coluna ocupa tudo no celular */
  padding-right: calc(var(--bs-gutter-x) * 0.5);
  padding-left: calc(var(--bs-gutter-x) * 0.5);
}

.col-md-4 { flex: 0 0 auto; width: 33.33333333%; } /* ← o "12 colunas" inteiro */
