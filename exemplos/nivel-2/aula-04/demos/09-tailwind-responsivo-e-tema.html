Demo 09 — no Tailwind não existe media query no seu código: existe prefixo

Mesma lógica mobile-first do Bootstrap, sintaxe diferente. md:grid-cols-2 é "duas colunas a partir de 768 px".

1. Responsividade por prefixo

grid grid-cols-1 gap-4 md:grid-cols-2 lg:grid-cols-3 — arraste a janela.

breakpoint ativo: base — abaixo de 640 px sm — a partir de 640 px md — a partir de 768 px lg — a partir de 1024 px xl — a partir de 1280 px

Repare: os pontos de quebra não são os mesmos do Bootstrap (576 / 768 / 992 / 1200). Aqui são 640 / 768 / 1024 / 1280. Trocar de framework significa trocar de régua — mais um argumento para não misturar dois.

2. Estados também são prefixos — e eles se combinam

hover:, focus-visible:, disabled:, dark:, motion-reduce: — é essa composição que torna o Tailwind poderoso e o HTML comprido ao mesmo tempo.

3. @theme: o outro lado da mesma moeda

Bootstrap

Você sobrescreve os tokens de um design pronto: --bs-btn-bg: #6f4e37.

Tailwind

Você declara os tokens do seu design e o framework gera as classes: @theme { --color-cafe: #6f4e37 } → nascem bg-cafe, text-cafe, border-cafe.

bg-cafe bg-cafe-escuro border-cafe · text-cafe bg-cafe/20 — opacidade sai de graça

Prova ao vivo: troque --color-cafe para #1d4ed8 na tag <style type="text/tailwindcss"> e recarregue: tudo nesta página muda de cor, com uma linha editada. Sem o @theme, você teria que caçar cada bg-amber-800 no HTML — é essa a pergunta de manutenção do desafio ⭐⭐.
