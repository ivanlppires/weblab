Para mostrar na aba Elements:

  • Nenhuma dessas classes sabe o que é um botão. px-4 é padding lateral; bg-amber-800 é uma cor da paleta; hover:bg-amber-900 é a mesma coisa dentro de :hover.
  • O Play CDN injeta uma tag <style> no topo do documento com o CSS que ele acabou de gerar. Procure por ela na aba Elements: é o compilador trabalhando ao vivo.
  • Na aba Network não existe hash integrity — conteúdo gerado não tem hash fixa. É por isso que o Tailwind entra no curso como experimento, não como dependência de produção (§7.1).
