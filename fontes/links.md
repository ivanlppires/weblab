Esta página reúne os links que valem a pena guardar: documentação oficial para consultar quando o exemplo da aula não bastar, sites para praticar sem sair do navegador, ferramentas que você vai usar em quase todo projeto e comunidades em português para quando travar sozinho não estiver ajudando. Não precisa decorar nada disso agora — volte aqui sempre que precisar.

## Documentação oficial

- [MDN Web Docs (pt-BR)](https://developer.mozilla.org/pt-BR/) — referência de HTML, CSS e JavaScript, com exemplos e tabela de compatibilidade por navegador.
- [Node.js — Documentação oficial](https://nodejs.org/docs/latest/api/) — referência completa da API do runtime usado no back-end das trilhas 2 e 3.
- [Express — Guia oficial (pt-BR)](https://expressjs.com/pt-br/) — como criar rotas, usar middlewares e tratar erros no framework HTTP do Node.
- [Vue.js — Guia oficial](https://vuejs.org/guide/introduction.html) — reatividade, componentes e Composition API, a base do Nível 3.
- [Vuetify — Getting Started](https://vuetifyjs.com/en/getting-started/installation/) — instalação, componentes e temas da biblioteca de UI Material Design para Vue.
- [Pinia — Guia oficial](https://pinia.vuejs.org/introduction.html) — gerenciamento de estado global recomendado para aplicações Vue 3.
- [Vue Router — Guia oficial](https://router.vuejs.org/guide/) — rotas, navegação programática e guardas de rota em SPAs Vue.
- [Vite — Guia oficial](https://vite.dev/guide/) — o bundler e servidor de desenvolvimento usado para criar e servir os projetos Vue.
- [MySQL Reference Manual](https://dev.mysql.com/doc/refman/8.4/en/) — sintaxe SQL, tipos de dados e administração do banco relacional usado no Nível 3.
- [Supabase Docs](https://supabase.com/docs) — banco Postgres gerenciado, autenticação, Row Level Security e API REST automática.
- [Firebase Docs](https://firebase.google.com/docs) — Firestore, Authentication e Hosting como alternativa de back-end gerenciado.
- [Docker Docs](https://docs.docker.com/) — imagens, contêineres e Docker Compose para empacotar e rodar aplicações.
- [nginx Docs](https://nginx.org/en/docs/) — configuração do servidor web/proxy reverso usado no deploy em VPS.

## Aprender praticando

- [Flexbox Froggy](https://flexboxfroggy.com/) — joguinho que ensina Flexbox fazendo sapos pularem para as posições certas.
- [Grid Garden](https://cssgridgarden.com/) — aprenda CSS Grid regando canteiros com as propriedades de grid corretas.
- [CSS Diner](https://flukeout.github.io/) — pratique seletores CSS "servindo" os pratos certos em cada nível.
- [freeCodeCamp (em português)](https://www.freecodecamp.org/portuguese/) — currículo gratuito com certificados de HTML, CSS, JavaScript e mais.
- [Exercism](https://exercism.org/) — exercícios de lógica e algoritmos com mentoria da comunidade, em várias linguagens.
- [Frontend Mentor](https://www.frontendmentor.io/) — desafios de HTML/CSS/JS a partir de designs reais, com níveis de dificuldade.
- [JavaScript30](https://javascript30.com/) — 30 projetos em JavaScript puro, sem framework e sem biblioteca.

## Ferramentas online

- [CodePen](https://codepen.io/) — editor online para protótipos rápidos de HTML/CSS/JS e para ver o código de outras pessoas.
- [StackBlitz](https://stackblitz.com/) — IDE no navegador que roda projetos Node/Vue completos sem instalar nada localmente.
- [CodeSandbox](https://codesandbox.io/) — ambiente online para criar e compartilhar projetos front-end e full-stack.
- [Regex101](https://regex101.com/) — testador de expressões regulares com explicação de cada parte do padrão.
- [Postman](https://www.postman.com/) — cliente para testar rotas de API, a mesma ferramenta usada nas aulas de back-end.
- [Can I Use](https://caniuse.com/) — tabela de suporte de recursos de HTML/CSS/JS por navegador.

## APIs públicas para praticar

- [ViaCEP](https://viacep.com.br/) — consulta de endereços a partir do CEP, sem necessidade de chave de API.
- [IBGE — API de Localidades](https://servicodados.ibge.gov.br/api/docs/localidades) — estados, municípios e regiões do Brasil em JSON.
- [BrasilAPI](https://brasilapi.com.br/) — CEP, CNPJ, feriados, bancos e outros dados brasileiros reunidos em uma API aberta.
- [JSONPlaceholder](https://jsonplaceholder.typicode.com/) — API fake com posts, comentários e usuários para treinar requisições CRUD.
- [PokéAPI](https://pokeapi.co/) — dados completos de Pokémon, ótima para praticar consumo de API com paginação.
- [OpenWeather](https://openweathermap.org/api) — previsão do tempo e clima atual por cidade ou coordenadas (exige chave gratuita).
- [The Dog API](https://thedogapi.com/) — imagens e informações de raças de cachorro, com chave gratuita opcional.
- [Rick and Morty API](https://rickandmortyapi.com/) — personagens, episódios e locais da série, sem necessidade de chave.

## Design, cores, fontes e ícones

- [Google Fonts](https://fonts.google.com/) — catálogo de fontes gratuitas para usar com `@font-face` ou `<link>`.
- [Coolors](https://coolors.co/) — gerador de paletas de cores com exportação para CSS/HEX.
- [Adobe Color](https://color.adobe.com/pt/create/color-wheel) — roda de cores para criar paletas harmônicas por regra de contraste.
- [Font Awesome](https://fontawesome.com/) — biblioteca de ícones vetoriais amplamente usada em projetos web.
- [Material Symbols](https://fonts.google.com/icons) — ícones do Material Design, os mesmos usados pelo Vuetify.
- [Heroicons](https://heroicons.com/) — ícones SVG simples e gratuitos, em versão outline e sólida.
- [unDraw](https://undraw.co/) — ilustrações SVG gratuitas e customizáveis por cor, ótimas para telas vazias.

## Acessibilidade

- [W3C WAI](https://www.w3.org/WAI/) — página oficial da iniciativa de acessibilidade do W3C, com as diretrizes WCAG.
- [WebAIM](https://webaim.org/) — artigos práticos sobre acessibilidade web, leitores de tela e boas práticas de formulário.
- [eMAG — Modelo de Acessibilidade em Governo Eletrônico](https://emag.governoeletronico.gov.br/) — recomendações de acessibilidade do governo brasileiro.
- [axe DevTools](https://www.deque.com/axe/devtools/) — extensão de navegador que audita acessibilidade direto no DevTools.
- [WebAIM Contrast Checker](https://webaim.org/resources/contrastchecker/) — verifica se a combinação de cores atende à taxa de contraste da WCAG.
- [NVDA](https://www.nvaccess.org/download/) — leitor de tela gratuito para testar navegação por teclado e ARIA no Windows.

## Performance e qualidade

- [Lighthouse](https://developer.chrome.com/docs/lighthouse/overview/) — auditoria de performance, acessibilidade, boas práticas e SEO integrada ao Chrome.
- [PageSpeed Insights](https://pagespeed.web.dev/) — roda o Lighthouse na sua URL pública e mostra métricas de campo (Core Web Vitals).
- [WebPageTest](https://www.webpagetest.org/) — teste de performance detalhado, com filme da renderização e de diferentes localidades.
- [web.dev](https://web.dev/) — guias do Google sobre performance, Core Web Vitals e boas práticas modernas de front-end.
- [GTmetrix](https://gtmetrix.com/) — relatório de performance com recomendações priorizadas por impacto.
- [Chrome DevTools](https://developer.chrome.com/docs/devtools/) — documentação das abas Elements, Network, Performance e Application do navegador.

## Deploy e infraestrutura

- [Netlify Docs](https://docs.netlify.com/) — deploy contínuo de sites estáticos e front-ends a partir do GitHub.
- [Vercel Docs](https://vercel.com/docs) — deploy de front-ends (e funções serverless) com integração automática ao Git.
- [Render Docs](https://render.com/docs) — hospedagem de back-ends Node, bancos de dados e sites estáticos com deploy automático.
- [GitHub Pages](https://docs.github.com/pt/pages) — hospedagem gratuita de sites estáticos direto de um repositório do GitHub.
- [GitHub Actions](https://docs.github.com/pt/actions) — automação de build, teste e deploy (CI/CD) disparada por eventos do repositório.
- [Let's Encrypt](https://letsencrypt.org/pt-br/) — certificados TLS/SSL gratuitos, a base do HTTPS configurado no nginx.
